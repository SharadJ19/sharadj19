## 🏗️ Featured Project

### ChowkSpot - Real-Time P2P Local Services Marketplace

[![Live Demo](https://img.shields.io/badge/Live_Demo-6366F1?style=for-the-badge&logo=vercel&logoColor=white)](https://chowkspot.vercel.app)
[![Source Code](https://img.shields.io/badge/Source_Code-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/sharadj19/chowkspot)

A full-stack marketplace connecting customers with local service providers across 80+ specialized categories. Built on a relational schema with atomic transaction scripts, dual-token JWT authentication, and live booking updates over WebSockets.

![React](https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB)
